# ÉLISE

**Everyday Language Immersion & Speaking Engine**: a French word, phrase and mini-dialogue every day,
themed around what's coming up in your week.

- `web/`: the app (GitHub Pages, installable on Android)
- `apps-script/`: the API (standalone Google Apps Script, data in the ÉLISE Google Sheet)
- [`SETUP.md`](SETUP.md): set up and install on the phone
- [`docs/SPEC.md`](docs/SPEC.md): the current spec ([original brief](docs/original-spec.md))
